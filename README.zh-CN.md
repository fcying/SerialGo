# SerialGo

[English](README.md) | 简体中文

面向 Windows 和 Linux 的原生串口调试助手, 支持文本和 HEX 收发, 接收日志, 文件传输及可编辑发送预设.

## 快速开始

1. Windows 运行 `SerialGo.exe`, Linux 在图形会话中运行 `SerialGo`. EXE 所在目录须可写, 以便创建和保存同目录的 `config.toml`.
2. 选择串口和波特率, 再点击 "打开". 初始波特率为 `115200`; 需要调整帧格式或控制线时点击波特率旁的 "配置".
3. 在发送区输入文本或 HEX 字节并点击 "发送". 需要时在 "选项" 中选择文本编码.
4. 上方窗口显示接收数据. 点击 "保存数据" 将当前显示日志导出为 `.txt`, 点击 "录制数据" 可在连接后开始保存原始接收字节.

底部从左到右为连接控制, 接收控制, 文件操作和发送输入区. 拖动横向分隔线可扩大底部工作区, 双击恢复紧凑默认布局. 分隔线位置不保存.

## 连接与波特率

- 启动时枚举串口, 每次通过鼠标或键盘展开端口下拉框时刷新. 关闭后重新展开即可重试, 不另设刷新按钮. 枚举失败保留原列表和选择.
- Windows 尽可能显示设备描述, 如 `COM12 USB-SERIAL CH340`; Linux 显示设备路径. 悬停可查看省略名称的完整内容, 连接锁定后仍可查看. 打开和保存使用实际设备名, 不含描述.
- 刷新保留仍可用的当前端口, 否则选第一项. 空列表清除选择并禁用打开按钮. 连接后锁定端口和波特率选择框.
- "串口配置" 可设置数据位, 校验位, 停止位, RTS 和 DTR. 设置全局共用, 不按设备分别保存; 底部状态栏显示当前帧格式. 已连接时仅可修改 RTS/DTR; 驱动错误会在对话框中提示, 不应用未确认的变更.
- "确定" 应用属性框变更; 取消, Escape 或关闭弹窗丢弃草稿. 参数未变时确认不写盘. 帧格式只在配置框编辑, 不在主面板重复显示.

波特率选择框初始提供 `9600`, `19200`, `57600`, `115200`, `921600` 和 `1000000`:

- "自定义..." 添加并选中波特率, 去重后按大小排序. 输入接受 `1` 到 `4294967295` 的整数, 实际支持范围由设备和驱动决定.
- 右键数值项选择删除并确认, 取消或 Escape 不修改. 删除当前值后选择剩余第一项.
- 主面板增删立即保存. 配置框内的增删在外层确定前均为草稿, 外层取消或 Escape 会丢弃.
- 列表删空后重启仍为空, 禁用打开按钮, 直到新增波特率. 也可退出程序后编辑 `config.toml` 的 `BaudRates`.

## 发送数据

- 文本支持 UTF-8 和 GB18030. 发送区的 HEX 开关接受连续字节或空格, 逗号分隔, 如 `01030000` 或 `01 03 00 00`.
- "自动换行" 对应 CRLF, 在发送末尾追加 `\r\n`, 与串口帧格式无关. 程序不自动计算或追加校验码, 协议需要的校验字节须自行写入.
- 勾选 "定时" 并设置毫秒间隔, 即可按该间隔重复发送当前内容.
- "发送" 开始发送当前内容; "清空发送" 清除输入. 文本和 HEX 模式在输入为空时均提示 "输入发送内容...". "停止" 可取消文件发送; 悬停可查看 "停止文件发送" 提示.

## 接收显示与文件

- "HEX 显示" 切换文本或 HEX. "选项 > 显示发送记录" 显示本机发送的 `TX >` 记录及接收的 `RX <` 记录, 不会再次发送数据.
- "时间戳" 按空闲间隔分包并添加时间戳. 在选项中设置 "时间戳分包超时", 默认 `20 ms`. 无效编辑保留为草稿并显示错误, 修正后才生效.
- "自动滚动" 跟随最新数据. 关闭后仍接收, 但保留当前视口; 重新开启后回到最新行. 选中文字时暂时暂停跟随, 清除选区后恢复跟随, 不会关闭自动滚动. 仅向上滚动不会关闭跟随. 自动滚动状态不保存.
- "清空" 清除接收日志. 底部显示 S/R 收发字节计数; "清计数" 清零. 串口参数和操作状态也会显示, 悬停可查看完整文字.
- "打开文件" 选择文件, 悬停 "发送文件" 可查看完整路径. "延时" 设置文件发送分块之间的毫秒等待, 最后一块后不额外等待.
- "保存数据" 将显示日志导出为 `.txt`. "录制数据" 将原始接收字节保存为 `.dat`. 如果录制跟不上串口接收, 会停止录制并报告错误, 不阻塞接收或静默丢弃数据. 停止录制, 断开串口或退出时刷新并关闭文件. 录制需要已连接串口, 重启后不会自动续录, 已完成的 `.dat` 文件保留在磁盘.

### 显示历史上限

在 "选项 > 数据显示 > 显示缓冲上限" 中选择 `200K`, `500K`, `1M`, `2M` 或 `5M`, 默认 `200K`. 单位采用十进制 (`K = 1000`, `M = 1000000`), 按原始事件数据字节数计算, 包含发送记录, 不计 HEX 展开和时间戳.

超限后整条删除最旧事件, 最新事件即使单条超限也保留. 调小上限立即裁剪历史, 调大不会恢复已淘汰数据. 不提供无限制选项或单独记录条数上限. 需要不受显示上限影响的原始数据时, 使用 "录制数据".

## 发送预设

点击 "扩展" 展开预设面板, 点击 "收起" 折叠.

- 新配置初始包含 `Preset 1` 至 `Preset 5`. 只显示实际配置条目, 最多 99 条, 不补齐空槽位.
- 每条可编辑备注, 内容, HEX/CRLF 开关和间隔. 支持单条发送, 按顺序发送勾选项, 或勾选循环后重复发送. 停止可结束当前任务.
- "新增" 追加空条目并滚动到该条. 删除须确认, 取消不修改. 剩余条目保留顺序并连续编号.
- 新增和确认删除立即保存, 空白条目也保留. 可以删空全部条目, 重启仍为空. 发送期间不能增删.

## 语言与外观

在接收控制区打开 "选项". 英文界面的语言按钮显示 **简体中文**, 中文显示 **English**, 表示目标语言. 控件, 对话框, 提示及已有状态立即切换, 无须重启, 并保存选择. 默认英文 (`en`), 简体中文使用 `zh-CN`; 缺失或无效语言值使用英文.

切换语言不翻译或重置串口数据, 用户输入, 文件, 预设备注和指令, 协议值, 或操作系统及第三方库原始错误. 两种语言的默认预设名均为 `Preset 1` 至 `Preset 5`.

选项还提供置顶, 文本编码, 显示历史, 显示发送记录, 时间戳分包超时及接收字体设置. 接收字体默认宋体, 9 磅, 黑色, 使用标准 16 色调色板. 发送内容和预设使用系统等宽字体, 中文使用字体回退. 图标已内嵌, 不须另放图标文件.

## 配置与数据安全

- 仅使用实际可执行文件同目录下的 `config.toml`, 并解析 EXE 符号链接. 不搜索工作目录或用户配置目录, 保存失败不回退到其他目录.
- 配置缺失时立即创建. 已有文件, 包括无法读取或解析的文件, 加载时不覆盖. 创建和保存失败会提示, 请保证 EXE 目录可写.
- 仓库的 [`config.toml`](config.toml) 是默认参考, 不是运行时依赖. EXE 同目录已有值保留, 缺失标量字段使用默认值. 预设列表缺失或显式为空时保持为空, 不恢复初始条目.
- 设置在实际使用时保存, 包括成功连接, 接受发送任务, 文件导出或接收存文件, 确认属性, 预设增删, 以及立即应用的显示, 语言或预设面板变更. 编辑不逐字写盘. 正常退出保存剩余草稿, 强制结束可能丢失草稿. 未修改的使用和退出不重写文件.
- 保存错误保持可见, 下次使用重试. 已存编码或分包超时无效时使用 UTF-8 和 `20 ms` 并显示启动警告, 加载不重写文件. 显示上限无效时使用默认值.
- 旧配置缺少 `BaudRates` 时迁移旧波特率值, 显式数组 (包括 `[]`) 优先. 旧发送校验和独立 `Packet` 设置被忽略, 下次正常保存时省略, 不因加载而重写. `Timestamp` 和 `PacketGap` 继续支持.

## 运行环境

- Windows amd64, 或带图形会话和 GTK 3 的 Linux amd64.
- 所选串口的读写权限.
- 可写的 EXE 所在目录, 用于创建和保存配置.

源码构建, 测试和部署见 [构建与验证流程](ARCHITECTURE.zh-CN.md#构建与验证流程).

## 限制

- 提供的构建面向 Windows amd64 和 Linux amd64. 波特率及控制线支持由驱动决定. 当前没有自动流控设置.
- Linux 窗口图标显示由窗口管理器或合成器决定, 仅标题栏无图标不能证明加载失败. 参见 [GTK 窗口图标约定](https://docs.gtk.org/gtk3/method.Window.set_icon.html).
- 实际收发需要物理或虚拟串口, 构建或 UI 启动成功不代表串口 I/O 已通过验证.
